Python/R/Matlab/Octave/Julia syntaxes are almost identical, just diverging through some basic language elements:
   
| Python   | R        | Matlab/Octave | Julia     |
|----------|----------|---------------|-----------|
| `a = b`  | `a <- b` | `a = b`       | `a = b`   |
| `True`   | `TRUE`   | `true`        | `true`    |
| `False`  | `FALSE`  | `false`       | `false`   |
| `None`   | `NULL`   | `[]`          | `nothing` |
| `a.b()`  | `a$b()`  | `a.b()`       | `b(a)`    |
